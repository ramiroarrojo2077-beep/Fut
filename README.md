# Doce Pasos

Juego de penales en 3D en el navegador. Es un solo archivo (`index.html`), sin build. Usa three.js (r128) desde cdnjs, así que necesita internet y un navegador con WebGL.

## Cómo jugar

Abrí `index.html` en el navegador. Cada equipo patea cinco penales, alternados; si quedan empatados se sigue a muerte súbita.

- **Pateando:** tocá el arco donde querés poner la pelota y frená la barra de potencia en la franja verde. Más fuerte va más rápido, pero se puede ir arriba.
- **Atajando:** la cámara pasa detrás del arco. Tocá hacia dónde tirarte. Si te tirás antes del remate, el pateador te puede leer y cambiar de palo.

Teclado: flechas para apuntar y `Espacio` para patear. Atajando: `←` `→` para tirarte (con `Shift`, arriba), `↑` salto, `↓` bloqueo.

Tres dificultades: Fácil, Normal y Difícil.
